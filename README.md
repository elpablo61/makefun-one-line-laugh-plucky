## The line

> At 2 a.m. my neighbour Pak Budi knocked to ask if my dog could keep it down, and my dog was asleep on his doormat.

One specific scene, one twist, no explanation — a micro-anecdote that sounds true,
calibrated against the verified top-10 winning lines of past one-liner bounties.

## How it works

`main.ts` (Node 22) writes the line to `$MAKEFUN_OUTPUT_DIR/entry.txt`
(default `/output/entry.txt`). The gate requires 1–200 characters; the program
refuses to write a line outside that range.

```sh
node main.ts
```
